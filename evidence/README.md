# Group B evidence

- `planned_queries.csv`: the 16 protocol expressions as a run checklist; a planned query is not an executed search.
- `access_tests.csv`: Desktop Commander terminal probes, distinct from browser access and search execution.
- `search_runs.csv`: fill only after actually running each database query with displayed count and export proof.
- `incoming_shared/`: four user-provided original ScienceDirect RIS files. These are incoming partial exports with no complete interface log; retain byte-for-byte.
- `shared_leads.csv`: papers from Group A and incoming RIS, all **unassessed by B**. This is a discovery queue and not a final included set.
- `preliminary_triage.csv`: reversible rules-assisted ordering of the 100 RIS occurrences. Its 10 repeated keys, 7 full-text leads, 8 uncertain and 75 likely out-of-scope items still need actual protocol screening before PRISMA use.
- `templates/`: blank canonical schemas for imports, duplicates, title/abstract votes, reports, QA and extraction. Keep IDs and source links stable.
- `protocol_amendments.md`: method changes after the submitted Task 1 baseline.
- `pilot/`: three DOI/source-version checks, provisional eligibility recommendations, five anchored pilot extraction rows and candidate BibTeX. Final publication-version and independent checks are pending.

Do not put licensed publisher PDFs or account information in this public repository. Keep per-paper quotes brief and track DOI plus page/figure references instead.
